Lab 6 - 

* When first assigned, I knew what I wanted to do with this lab, reuse the idea I had for an OOP assignment 2 years ago
* The idea was to create a basic RPG battle simulation. There would be some classes, which change base values of the player like Health, Attack etc. The player would then fight a pre built enemy
* This time my code was much more efficient
* Character was built a superclass with the intent of having each enemy as a subclass, but due to time I prebuilt one somewhere else
* The classes were defined as an Enum since all the different values for the class are defined by numbers
* The logic behind the rules of the game were: You can either attack or rest, rest lets you regain health and stamina. Whenever you attack, you lose stamina, if you have less than required, you need to rest.
* The damage for the attacks are not defined, they get the attack value of the Character and randomly goes from 0 to that value. If the damage is 0, the character loses double stamina, if it hits max damage, the damage is double.

* The javaFX design behind the application was simple. A window to start the game, a text box for the game, 2 action buttons (attack and rest) and a counter of rounds with small circles in the upper right side of the screen. 
* The names of the player and enemy go from green to red to simulate the current health situation of their character
